# 🎮 CRIN Aventuras de Lectoescritura (Prototipo Móvil)

¡Bienvenido al prototipo de **CRIN Aventuras de Lectoescritura**! Esta aplicación web está diseñada específicamente para ser probada en teléfonos móviles o tabletas, ofreciendo un entorno accesible, lúdico y altamente gratificante para niños con autismo, trastornos del lenguaje (TEL) y necesidades de apoyo escolar del Centro CRIN.

---

## 🚀 ¿Cómo probar la aplicación?

1. **En la computadora / navegador:**
   - Abre el archivo [index.html](file:///C:/Users/Vivic/.gemini/antigravity/scratch/crin-aventuras-lecto/index.html) haciendo doble clic o arrastrándolo a cualquier navegador (Chrome, Edge, Safari, Firefox).
   - Puedes activar el modo de inspección móvil en Chrome/Edge (`F12` -> icono de teléfono) para ver el marco con resolución de smartphone.

2. **En un teléfono celular (Android o iPhone):**
   - Sirve la carpeta `crin-aventuras-lecto` en tu red local (o envíate el archivo `index.html`) y ábrelo en el navegador de tu celular.
   - En Safari o Chrome, presiona **"Agregar a la pantalla de inicio"** para usarla como una aplicación nativa instalada (PWA).

## 🌟 Características incluidas en este Prototipo

1. **Mapa de Aventuras por Mundos:**
   - *Bosque de las Letras* (Método Global / Inicial).
   - *Cueva de las Sílabas* (Intermedio / Fonológico).
   - *Castillo Tarea CRIN* (Vocabulario de apoyo escolar).

2. **Mecánica de Construcción de Palabras con Apoyo Auditivo:**
   - Síntesis de voz en español nativo para pronunciar letras, fonemas y palabras completas al tocarlas.
   - Pictogramas claros y botones adaptados para motricidad fina.
   - Animaciones y efectos de sonido al acertar (generados por Web Audio API).

3. **Vestimienta de Héroe y Mascotas:**
   - Creador de avatar donde el niño puede cambiar su personaje (astronauta, superhéroe, mago) y seleccionar su mascota acompañante (perrito, gatito, dragón).

4. **Álbum de Cromos/Stickers de Premio:**
   - Sección de recompensas donde los niños coleccionan stickers digitales ganados en sus misiones.

5. **Panel de Terapeutas / Padres (⚙️ CRIN):**
   - Posibilidad de agregar palabras personalizadas para la semana.
   - Interruptor de fuente adaptada para legibilidad.
